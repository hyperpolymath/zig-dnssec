Standalone runs on random input are dominated by cheap early rejections; the
coverage-guided and mutated-seed runs are the stronger evidence. The differential
validator campaign is slow (each run is a full chain validation with signature checks)
and reached 2,541 of 29,625 instrumented points (8.6 %); the denominator counts the
whole program, including standard-library code the harness never calls, so the figure
says little on its own. Longer validator campaigns are an open item.
