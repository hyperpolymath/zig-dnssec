= Proof Needs — zig-dnssec

The proofs zig-dnssec still needs, in order of the risk they would retire.

* What is already proved, tested or argued: the ledger in
  link:../../EXPLAINME.adoc#proof-ledger[EXPLAINME.adoc].
* Grades, receipts, assumptions and toolchain deviations:
  link:PROOF-STATUS.adoc[PROOF-STATUS.adoc].
* Which prover carries which obligation: PROOF-POLICY §1 (`hyperpolymath/standards`,
  `3-practice/PROOF-POLICY.adoc`). In short, Idris2 for the C ABI and other
  engineering properties of this repository, and Agda for theory, rechecked in Rocq and
  Lean. No Mathlib.

*Tier*: T3 — Standard, as set at mint. It has not been reassessed for a security-relevant
validator; reassessing it is the owner's call.

== Escape hatches

What counts as an escape hatch, and how any that are allowed are budgeted and recorded,
is set by `docs/TRUSTED-BASE-REDUCTION-POLICY.adoc` in `hyperpolymath/standards`. None
of zig-dnssec's own proof files uses one: no `believe_me`, `assert_total`, `postulate`,
`sorry`, `Admitted` or `axiom`.
