= Proof Status — zig-dnssec
:toc:

This is zig-dnssec's proof-status file under PROOF-POLICY (`hyperpolymath/standards`,
`3-practice/PROOF-POLICY.adoc` at `9bdf864cc7f2c8e24b4df84bf00d04158eee3ad5`).

* Every proof obligation is a row of the proof ledger in
  link:../../EXPLAINME.adoc#proof-ledger[EXPLAINME.adoc]. This file does not repeat
  those rows.
* This file holds what the policy asks for beyond the ledger: the theory theorems'
  Proof Witness Grades with their receipts (§8), the import cone (§1.1), the assumptions
  at the boundaries (§1.1), and the toolchain deviations (§6).
* What is still needed is in link:PROOF-NEEDS.adoc[PROOF-NEEDS.adoc].

== Engineering proofs (Idris2)

The C ABI's interface contract is proved in Idris2 (PROOF-POLICY §1, "APIs, ABIs and
engineering properties"):

* `src/interface/Abi/Types.idr`: codes, exact decoding, and no answer with a failed
  verdict;
* `src/interface/Abi/Layout.idr`: the verdict struct's layout;
* `src/interface/Abi/Foreign.idr`: the safe wrapper.

Engineering proofs carry §5 status tokens only and are not graded on the PWG ladder
(§8.1).

* *Checker:* Idris2 0.7.0, built from the release commit
  `27780073c8631826d846499840b3857d9b9a4fd5`.
* *Invocation:* `idris2 --typecheck src/interface/abi.ipkg`. The CI step also fails on any
  `Error` line, because `idris2` can exit 0 with one.
* *Escape hatches:* every module is `%default total`. None contains `believe_me`,
  `assert_total`, `assert_smaller`, `idris_crash`, `unsafePerformIO`, a hole or `partial`
  (the scan uses the patterns of `mathesis/scripts/census/proof-holes.sh`).
* *Import cone:* the `base` package of Idris2 0.7.0. Its own primitives (including the
  `Data.Buffer` FFI) are the Idris2 runtime's trusted base. That reliance is the `argued`
  FFI-marshalling row in the ledger.

== Theory proofs: chain-of-trust soundness

The theorems `secure-sound`, `insecure-sound`, `complete` and `fail-closed` are theory
(§1). They are statements about the decision procedure of any validator that walks signed
keys down from a trust anchor, not about one repository's code.

[cols="1,3",options="header"]
|===
| Field | Value

| Source of truth
| `verification/proofs/agda/ChainOfTrust.agda` (Agda)

| `pwg`
| `2ii`

| `foundation_diverse`
| `false` (Agda, Rocq and Lean are all dependent type theories, §8.3)

| Agda leg
| route: source; §5: `PROVEN`; §2.2: `AGDA-VERIFIED`

| Rocq leg
| route: `re-proved`; §5: `PROVEN`; §2.2: `RECONCILED`
  (link:../../verification/proofs/CORRESPONDENCE.adoc[CORRESPONDENCE.adoc])

| Lean leg
| route: `re-proved`; §5: `PROVEN`; §2.2: `RECONCILED`
  (link:../../verification/proofs/CORRESPONDENCE.adoc[CORRESPONDENCE.adoc])

| Axioms
| none in any leg: Agda `--safe` with no postulates; Rocq `Print Assumptions`:
  "Closed under the global context" for each theorem; Lean `#print axioms`: "does not
  depend on any axioms" for each theorem

| Residual assumptions
| `verify` is a parameter: unforgeability of the signature algorithms is outside the
  proof. The model's scope, and the model-to-code link (`argued`), are as listed in
  CORRESPONDENCE.adoc.
|===

The grade is `PWG-2ii`. `PWG-1` additionally needs a current receipt for every witness
from a headless pinned run on each commit. The `theory-proofs` CI job writes those
receipts (`scripts/theory-receipts.sh`). Until a CI receipt exists for the commit in
question, the grade stated here is `PWG-2ii`.

=== Import cone (§1.1)

* *Agda:* root module `ChainOfTrust`; flags `--safe --without-K --cubical-compatible`; no
  imports; postulate count 0 (`--safe`, plus the comment-aware scan in
  `scripts/theory-receipts.sh`); no library.
* *Rocq:* the prelude only; no `Require`.
* *Lean:* core only; no imports, no Mathlib.

== Assumptions at the boundaries (§1.1)

Each assumption is an `argued` row in the ledger:

* *Idris2 FFI marshalling:* the Chez backend of Idris2 0.7.0
  (`27780073c8631826d846499840b3857d9b9a4fd5`) passes values as the `%foreign` types in
  `src/interface/Abi/Foreign.idr` say.
* *Signature verification:* Zig 0.17.0's `std.crypto`. The RFC known-answer vectors in
  `tests/vectors.zig` test the calls, not the primitives.
* *TLS:* Zig 0.17.0's `std.crypto.tls.Client`, used by the DoH transport.

== Toolchain deviations (§6)

== Template proof files

The template ships example proofs under `verification/proofs/`: `agda/Properties.agda`,
`coq/TypeSafety.v`, `lean4/ApiTypes.lean`, `idris2/` and `tlaplus/`. They are not
zig-dnssec obligations and have no ledger rows. `scripts/check-proofs.sh` still checks
them against their MANIFEST entries, so a change in their state shows up.
