== Overview

This guide covers building and packaging zig-dnssec for distribution on your
platform. zig-dnssec is a library with one command-line tool, `dnssec-stub`, and a
C ABI (`libzig_dnssec` and `zig_dnssec.h`). It has no configuration file, and
`just install` and per-instance deployment are not wired. Only the paths below are.

== Build Dependencies

Zig 0.17.0, `just` (1.42 or later), and Idris2 0.7.0 for the ABI model checks that `just test` runs.

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/zig-dnssec.git
cd zig-dnssec
just build
----

Output, under `zig-out/`:

* `bin/dnssec-stub`: the CLI (its exit status is the verdict: 0 secure,
  1 insecure, 2 bogus, 3 indeterminate, 4 usage or transport error)
* `lib/libzig_dnssec` (static and shared) and `include/zig_dnssec.h`, from
  `zig build ffi`

For a release build use `zig build -Doptimize=ReleaseSafe`; package those files
directly, since there is no install recipe.

== Packaging

=== Guix

[source,bash]
----
guix build -f build/guix.scm
----

This packages the source tree under `share/zig-dnssec/`.

=== Container

[source,bash]
----
just container-build
----

This builds `build/container/Containerfile` and tags the image
`ghcr.io/hyperpolymath/zig-dnssec:latest`. `CT_REGISTRY` and `CT_TAG` override
the registry and tag. `just container-push` publishes the same reference.

== Updating

[source,bash]
----
git pull
just build
just test
----
