:toc:

== Overview

This guide covers packaging, deploying, and maintaining zig-dnssec for
distribution on your platform.

== Runtime Dependencies

Zig 0.17.0, `just` (1.42 or later), and Idris2 0.7.0 for the ABI model checks that `just test` runs.

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/zig-dnssec.git
cd zig-dnssec
just build-release
----

Output: `zig-out/`

== Packaging

=== Guix

[source,bash]
----
guix build -f build/guix.scm
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t zig-dnssec .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/zig-dnssec/`
| Data files, assets

| `$PREFIX/share/doc/zig-dnssec/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/zig-dnssec/config.toml`

Fallback: `$HOME/.config/zig-dnssec/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just run --version   # Version check
just run --selftest  # Built-in self-test
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update zig-dnssec`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/zig-dnssec-instance1 --config=/etc/zig-dnssec/instance1.toml
just install --prefix=/opt/zig-dnssec-instance2 --config=/etc/zig-dnssec/instance2.toml
----

Each instance has isolated config, data, and logs.
