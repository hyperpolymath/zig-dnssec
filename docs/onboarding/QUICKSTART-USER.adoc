== What is zig-dnssec?

Experimental pure-Zig DNS wire-format codec and DNSSEC validator with a
DNS-over-HTTPS stub client: it authenticates answers from an untrusted upstream
resolver to a configured trust anchor.

It is a library. There is no installer and no long-running application:
`just install` and `just run` are not wired, and there is no configuration file.
It is experimental and not independently reviewed; read the warning in the
link:../../README.adoc[README] before relying on it.

== Prerequisites

* Zig 0.17.0
* *just*, the task runner (https://github.com/casey/just[install guide])

== Build and test

[source,bash]
----
git clone https://github.com/hyperpolymath/zig-dnssec.git
cd zig-dnssec
just build
just test
----

`just build` writes its output to `zig-out/`. To use the library from your own
Zig project, follow "Using it" in the link:../../README.adoc[README].

== Container

[source,bash]
----
just container-build
----

This builds `ghcr.io/hyperpolymath/zig-dnssec:latest` from
`build/container/Containerfile`.
