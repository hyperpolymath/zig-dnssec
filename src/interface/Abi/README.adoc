= Idris2 model of the C ABI

`Types.idr` (codes, round trips, what a verdict permits), `Layout.idr` (the verdict
struct, with alignment and no-overlap proofs) and `Foreign.idr` (bindings and the safe
wrapper). Typecheck with `idris2 --typecheck src/interface/abi.ipkg`. See
`../README.adoc`.
